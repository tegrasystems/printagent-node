# Support

## Community support

The Community Edition is supported by the community on a **best-effort** basis. There is no service level agreement and no guaranteed response time. We aim to respond to new questions and bug reports within 5 business days.

| I need... | Where |
|---|---|
| To ask a question | [Discussions → Q&A](https://github.com/tegrasystems/printagent-node/discussions/categories/q-a) |
| To suggest a feature | [Discussions → Ideas](https://github.com/tegrasystems/printagent-node/discussions/categories/ideas) |
| To report a reproducible bug | [Issues](https://github.com/tegrasystems/printagent-node/issues/new?template=bug_report.yml) |
| To report a vulnerability | [SECURITY.md](SECURITY.md) — never in a public issue |
| Help with a cloud subscription | [info@tegrasystems.nl](mailto:info@tegrasystems.nl) |

Before posting, please read the [installation guide](docs/installation.md), the [troubleshooting guide](docs/troubleshooting.md) and the [FAQ](docs/faq.md), and search existing discussions and issues.

## What to include

For a bug report, use the issue template. It asks for the node version, Windows version, node mode, printer model, steps to reproduce and a relevant log excerpt. Remove tokens, passwords and company data before posting.

## Cloud subscriptions

The paid PrintAgent cloud edition includes e-mail support. Terms and response times are described on [printagent.app](https://printagent.app). Use [info@tegrasystems.nl](mailto:info@tegrasystems.nl) for account, subscription and billing questions.

## What we cannot help with

- configuring your network, firewall or VPN;
- repairing or configuring third-party printer hardware;
- writing custom ZPL for a specific label or printer;
- issues caused by unsupported modifications or third-party tools.

## Triage

New bug reports are labeled `needs-triage`. We may ask for more information with the `needs-info` label; if there is no response within 14 days, the report may be closed. Closed reports can be reopened with new information.
