# Contributing

PrintAgent Node is a proprietary product; the source code is not public. You can still help.

## Report a bug

Use the [bug report form](https://github.com/tegrasystems/printagent-node/issues/new?template=bug_report.yml). Search existing issues and discussions first, and include the version, a log excerpt, your printer model and the steps to reproduce. Remove tokens, passwords and company data.

## Ask a question or suggest a feature

Questions go to [Discussions → Q&A](https://github.com/tegrasystems/printagent-node/discussions/categories/q-a). Feature ideas go to [Discussions → Ideas](https://github.com/tegrasystems/printagent-node/discussions/categories/ideas), where others can vote.

## Improve the documentation

Documentation and examples live in this repository. Pull requests that fix errors, clarify steps or add a useful example are welcome.

- Keep a change focused: one topic per pull request.
- Describe what changed and why.
- Keep commands, code and UI labels unchanged unless the change is about them.
- By contributing, you agree that your contribution is licensed under the same terms as the rest of this repository (see [LICENSE.md](LICENSE.md)) and that Tegra Systems BV may use, edit and publish it.

We may edit or decline contributions that do not fit the product or the documentation style.

## Translations

Corrections to the Dutch and German documentation are welcome. Keep product names, commands and UI labels as they are.

## Please do not

- paste tokens, passwords, customer data or license keys;
- open a public issue for a security vulnerability — use [SECURITY.md](SECURITY.md);
- submit source code for the closed-source components;
- open a pull request that changes licensing or branding.

## Code of conduct

By participating you agree to the [code of conduct](CODE_OF_CONDUCT.md).
